## CI/CD & Deployment

**Hosting:**
- **GitHub Pages** — Serves static HTML from the `main`/`master` branch of `tariqbaater/tariqbaater.github.io`

**CI Pipeline:**
- **None detected.** No `.github/workflows/`, CI config, or automated build pipeline exists.
- Deployment is **manual** via `scripts/publish-blog.sh`:
  1. Writes Markdown to `my-hugo-site/content/posts/<year>/<slug>.md`
  2. Runs `hugo --destination` to build static files
  3. `git add -A`, `git commit`, `git push origin <branch>`

**Deployment script:** `scripts/publish-blog.sh`
- Accepts post title and content (stdin or `--file`)
- Auto-generates URL slug from title
- Detects default branch (`main` or `master`)
- Builds with Hugo and pushes to GitHub Pages

**Auto-deploy script:** `scripts/prayer-timings-autodeploy.sh`
- Monitors a separate repo (`github.com/tariqbaater/Prayer_Timings`) for changes
- Polls remote SHA and pulls if different
- Runs on a remote server (`/home/clawbot/...`) — not part of this blog repo directly
