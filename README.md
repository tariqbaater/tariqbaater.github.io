# Tariq Baater Blog

A personal blog and portfolio built with Hugo, deployed to GitHub Pages.

## Overview

This project is a static site generated by [Hugo](https://gohugo.io/) using the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme. The site features a blog, CV page, about page, and category/tag archives.

## How Hugo Works

### Content Flow
1. **Write**: Add Markdown files to `my-hugo-site/content/posts/`
2. **Build**: Run `hugo` to generate static HTML
3. **Deploy**: Copy HTML to repo root for GitHub Pages

### Post Frontmatter
```yaml
---
title: "Post Title"
date: 2026-04-07
draft: false
categories: ["Retail Operations"]
tags: ["KSA Retail", "Technology"]
weight: 1
---
```

### Taxonomy (Categories & Tags)
Defined in `hugo.toml`:
```toml
[taxonomies]
  category = "categories"
  tag = "tags"
```

Hugo auto-generates:
- `/categories/` — list of all categories
- `/categories/retail-operations/` — posts in that category
- `/tags/` — list of all tags

### Static Pages (CV & About)
These are **not Hugo-managed**. They're plain HTML files in:
- `/cv/index.html`
- `/about/index.html`

To convert them to Hugo-managed content, create:
- `my-hugo-site/content/about.md`
- `my-hugo-site/content/cv.md`

## Scripts

### publish.sh
Builds the Hugo site and deploys to GitHub Pages.
```bash
bash scripts/publish.sh
```

### research-agent.sh
Generates a research post template for daily KSA retail research.
```bash
bash scripts/research-agent.sh
# Creates: my-hugo-site/content/posts/2026/research-YYYY-MM-DD.md
```

### setup-cron.sh
Sets up daily cronjob at 8AM to run research agent.
```bash
bash scripts/setup-cron.sh
```

## CI/CD

GitHub Actions automatically builds and deploys on push to `main` when content in `my-hugo-site/content/` changes.

## Publishing a New Post

1. Create a Markdown file in `my-hugo-site/content/posts/2026/`:
   ```bash
   # Example: my-hugo-site/content/posts/2026/my-new-post.md
   ---
   title: "My New Post"
   date: 2026-04-07
   draft: true
   categories: ["Blog"]
   tags: ["Example"]
   weight: 1
   ---
   
   Your content here...
   ```

2. Set `draft: false` when ready to publish

3. Run publish:
   ```bash
   bash scripts/publish.sh
   ```

## Customization

### Theme Configuration
Edit `my-hugo-site/hugo.toml`:
- Site title, description
- Social icons (LinkedIn, GitHub, Email)
- Menu items
- Theme params (colors, features)

### Adding Categories/Tags
Simply add them to post frontmatter:
```yaml
categories: ["Retail Operations", "Technology"]
tags: ["KSA", "Dark Store"]
```

Hugo auto-creates the taxonomy pages.
